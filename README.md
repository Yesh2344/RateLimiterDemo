## Overview

RateLimiterDemo is a minimal yet production‑ready example of a REST API with a **token‑bucket rate limiter** implemented in Python (Flask) and a simple front‑end that consumes the API. 
It demonstrates:

* Clean configuration handling (`.env`, `config.py`)
* Reusable utility module (`rate_limiter.py`)
* Proper logging and error handling
* Unit testing with `pytest`
* Modern HTML/CSS/JS (ES6 modules, responsive design)
